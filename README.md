# SmartWerk.art – statische Rekonstruktion

Eigenständige mehrseitige HTML/CSS/JavaScript-Version auf Basis des Chatverlaufs und des bereitgestellten Shop-Screenshots.

## Seiten
- `index.html` – Startseite
- `3d-druck.html` – 3D-Druck + Konfigurator-Mockup
- `individuell.html` – individuelle Anfertigung
- `shop.html` – Shop mit 4/2/1 responsive Grid
- `projekte.html` – Projekte
- `stl-dateien.html` – Wissen & STL-Quellen
- `kontakt.html` – Kontakt
- `warenkorb.html` – statischer JS-Warenkorb
- `impressum.html`, `datenschutz.html`, `agb.html` – Platzhalter für bestehende Rechtstexte

## Gemeinsame Dateien
- `styles.css` – kompletter Look & Responsive Design
- `script.js` – globaler Header/Footer, Mobile-Menü, Produkte, Warenkorb und Konfigurator-Mockup
- `assets/` – aus dem bereitgestellten Shop-Screenshot abgeleitete Produktbilder

## Starten
Einfach `index.html` im Browser öffnen. Noch besser: Ordner mit einem kleinen lokalen Webserver ausliefern, z. B. über VS Code Live Server.

Das SmartWerk-Logo und das Hero-Bild werden entsprechend der Vorgabe über die bestehenden SmartWerk-URLs geladen.
